# dsh-session-desk

Session grouping and trash, a hover-expand chat minimap, a conversation-header board tab, a copied appearance theme, and a draggable status pet for the DeepSeek Harness web GUI.

## Install

```bash
dsh plugin --profile web add link:/Users/laiweibin/work/workSoftware/dhs-plugins/dsh-session-desk
```

Restart or hard-refresh the web GUI after installing.
